## Additional audit observations

Catalogue refresh now validates, bounds and atomically persists a snapshot before publishing it, has context cancellation and visible error state. Optional runtime statistics are explicit, secret-free and do not mutate quality. Prompt preview uses the real engine renderer. Empty collections are normalized. Interrupted polling is visible rather than swallowed. Modern `golang.org/x/sys v0.44.0` replaces the obsolete Windows dependency. Runtime artifacts are verified before build. Release generation lives in versioned Go code, not an undocumented /tmp script; it excludes crash dumps/node_modules/private configuration and verifies extracted source reproducibility.

## Deliberately unchanged boundaries

No GetDIBits, Python runtime, consumer chat UI, external normal-mode browser, Windows system VPN, process concealment, undocumented provider-specific scheduler branches or automatic pipeline rewrites were introduced. Sing-box/OpenCode remain separate bundled runtimes. Studio uses a narrow MIT patch to the existing Go host library, not a new UI framework.

The old audit repros now test expected behavior and are in the ordinary regression suites. Native-only acceptance is written and cross-compiled, but not falsely reported as executed. A green Linux suite is not a Windows desktop sign-off.
