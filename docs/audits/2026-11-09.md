# Аудит репозитория от 9 ноября 2026 года

Проверена рабочая копия AIOverlay-go в ветке `feature/audio-context-029`, исходный HEAD `ea156969f22b89e5e4c72f6b1767264cb68baeb3`. В ней уже были незакоммиченные изменения контрактов, сессий и обработки запросов. Они сохранены; исправления аудита добавлены поверх них. Новые коммиты и push не выполнялись.

Исправлены воспроизведённые ошибки безопасности, конкурентности, сохранения настроек и UI. Общая проверка с race detector, Windows cross-build и браузерные тесты проходят. Проверки исходников AIOverlay и npm-зависимостей не находят известных уязвимостей. У внешнего sing-box остаётся отдельный нерешённый риск: 26 advisory IDs в 10 зависимостях официального runtime. Это не позволяет назвать весь дистрибутив свободным от известных уязвимостей.

## Область проверки

Проверены Go core и конфигурация, HTTP/native границы, клиенты провайдеров, управление дочерними процессами, веб-интерфейс, тестовые команды, упаковка исходников, Go/npm-зависимости и поставляемый sing-box. Проверка проводилась на Linux amd64. Windows-код прошёл статический анализ и кросс-компиляцию; интерактивного Windows-сеанса не было.

Сохранённое исходное состояние: `build/audit-2026-11-09/baseline-status.txt`, `baseline-hashes.json`, `baseline-user-changes.patch` и `baseline-user-files.tar.gz`. Это локальные файлы проверки, исключённые из Git. Прежний sing-box и его pins сохранены в `build/audit-2026-11-09/runtime-before/`; старый и новый бинарные объекты есть в локальном Git LFS cache.

## Зависимости и инструменты

Минимальная версия Go повышена с 1.27.1 до 1.27.3. Первоначальный `govulncheck` нашёл 11 достижимых advisories стандартной библиотеки в исходниках AIOverlay; после обновления проверки Linux/amd64 и Windows/amd64 возвращают `No vulnerabilities found`. Обновление соответствует [официальным исправлениям Go](https://go.dev/doc/devel/release). `go mod tidy` исправил классификацию прямой зависимости `golang.org/x/sys` и удалил ненужные суммы без массового обновления библиотек.

В рабочее окружение установлены Git 2.53.0, Git LFS 3.7.1, Go 1.27.3, Node.js 22.22.1/npm 9.2.0, C/C++ toolchain с GCC 15.2.0, curl, CA certificates, zip/unzip, pkg-config, ShellCheck 0.11.0, actionlint 1.7.12 и govulncheck 1.9.0. Установлены зафиксированные npm-зависимости и Chromium с системными библиотеками для Playwright. Архив Go сверён с SHA-256 официального каталога загрузок. Системный Go доступен через `/usr/local/bin/go`.

Добавлены `scripts/check.sh` и `.github/workflows/ci.yml`. Скрипт не изменяет пользовательский config и готовые release artifacts. CI использует Go из `go.mod`, Node 22, минимальное разрешение `contents: read`, ограничение времени и actions, закреплённые полными commit SHA. Он запускает race/UI-проверки и сканирование зависимостей. YAML проверен actionlint; запуск на GitHub в рамках аудита не выполнялся.

README приведён к текущей схеме конфигурации 5, действительным командам тестов и флагам релизной проверки. Обновлены SECURITY, notices и версия runtime в интерфейсе. Исторические результаты в VERIFICATION отделены от текущего прогона.

Ограничения режима описаны в [документации govulncheck](https://pkg.go.dev/golang.org/x/vuln/cmd/govulncheck).

## Границы результата

Реальные AI-провайдеры и удалённые VPN-серверы не вызывались. Тесты используют фиктивные ключи, локальные серверы и временные конфигурации. Полный браузерный набор проверяет Chromium и имитирует native bridge. Физический Windows WebView2, WASAPI, горячие клавиши, capture protection и сетевой egress внешних SDK требуют проверки на Windows. Go scanner не проверяет Bun/OpenCode и нативный libcronet.

Пользовательский `config.json`, история Git и прежние `dist/`/`releases/` не изменялись. Готовые архивы из прежних запусков не содержат эти исправления и не сертифицированы текущим прогоном. Новая сборка выпуска должна выполняться отдельно из проверенного состояния с учётом оставшихся findings sing-box.
